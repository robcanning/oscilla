# Preface {.unnumbered}

This manual documents Oscilla, an open-source browser-based framework for creating animated, cue-driven graphic scores. It is generated from the same source files as the online documentation at [oscilla.kompot.si/docs](https://oscilla.kompot.si/docs/).

The manual covers installation, score authoring, the cue DSL, animation, control systems, session features, and developer reference. For the most up-to-date version, consult the online documentation.
