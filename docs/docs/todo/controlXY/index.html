controlXY — Touch-based XY Control Pad

controlXY defines a persistent, touch-only XY control surface embedded directly in the score. It constrains a draggable handle to a bounding shape and continuously publishes normalized X/Y values for control and modulation.

Unlike time-based cues, controlXY is always active, has no playhead semantics, and is evaluated at assign time.

Syntax

controlXY(
  uid: <string>,
  bounds: <element-id>,
  handle: <element-id>,
  osc: <bool|number>,
  oscAddr: <string>
)

The cue expression is attached to the bounding element.

Parameters

Parameter Type Required Description
uid string yes Unique identifier for the control pad. Used for publishing and parameter binding.
bounds element id yes ID of the SVG element that defines the XY constraint area.
handle element id yes ID of the SVG element that is draggable inside the bounds.
osc `true false number`
oscAddr string no Custom OSC address (without leading /). Defaults to controlXY/<uid>.

Coordinate System

  • X axis

    • Left = 0.0
    • Right = 1.0

  • Y axis (musical convention)

    • Bottom = 0.0
    • Top = 1.0

All values are normalized to the bounding box.

Published Signals

controlXY:<uid>.x   // 0.0 – 1.0
controlXY:<uid>.y   // 0.0 – 1.0

These signals can be used anywhere parameter binding is supported.

OSC Output (optional)

If OSC is enabled, each update sends:

/<oscAddr> <x> <y>

Example default address:

/controlXY/pad1 0.42 0.87

OSC output is throttled to avoid flooding.

Authoring Pattern (Canonical)

Bounding element (carrier + constraint)

padArea controlXY(
  uid: pad1,
  bounds: padArea,
  handle: padDot
)
  • Carries the cue
  • Defines the XY space
  • Is not draggable

Handle element (draggable)

padDot
  • Must have a visible fill
  • Must not contain DSL
  • Receives pointer events

Behaviour

  • The handle can be freely dragged only inside the bounding element.
  • The cue is activated immediately on load.
  • No playhead intersection.
  • No animation.
  • No duration, easing, looping, or timing parameters.

Example Uses

Live scaling

scale(uid:box1, sx: pad1.x, sy: pad1.y)

Synth control

synth(uid:s1, freq: pad1.x[100,2000], amp: pad1.y)

Spatial / navigation control

o2p(path:loopA, start: pad1.x, end: pad1.y)

Notes

  • controlXY is a control-plane cue, not a temporal cue.
  • It is registered during assignCues(), not via the playhead dispatcher.
  • The bounding element should typically have fill: none to avoid intercepting pointer events.
  • The handle element must have pointer-events enabled and a visible fill.

Summary

controlXY turns the score itself into a tactile controller surface, enabling direct spatial control of sound, animation, and interaction parameters without leaving the notation.
