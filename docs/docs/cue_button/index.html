button() --- Clickable Buttons Inside the Score

button() creates clickable UI buttons that trigger cues directly from within the score. It overlays a real HTML button on top of an invisible SVG placeholder.

Syntax

Place an element whose ID begins with button(:

id="button(triggerExpr …)"

Examples:

button(nav(page:2)) button(pause(4)) button(osc(param:grainRate,val:0.2))

Labels

Automatic label priority:

  1. style(label:"…") override\
  2. UID in the trigger\
  3. cue action\
  4. fallback "button"

Example:

button(nav(page:3))_style(label:"Next Page")

Styling

button(nav(page:3))_style( label:"Next", size:"120x45", color:"#0379ff", textcolor:"#ffffff", font:"Inter", fontsize:16, active:"flash" )

Supported keys

Key Meaning

label Custom button text size:"W×H" Width + height (px) color Background textcolor Text color font Font family fontsize Font size (px) active:"flash" Flash animation when clicked

Positioning

Buttons are positioned based on the SVG placeholder and aligned into UI containers (singlePage-content, pageOverlay, or scoreInner). The SVG marker is hidden unless part of reuse().

Optional offsets:

button(nav(page:4))_offsetX(10)_offsetY(-8)

Removing / Hiding

Hide markers:

hideAllButtonPlaceholders(svgRoot)

Destroy all created buttons:

destroyAllCueButtons()
